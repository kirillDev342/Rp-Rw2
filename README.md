# Soul Knight: Neon Dungeon

Играбельный браузерный roguelite-шутер в пиксельном стиле. Главное меню использует композицию `Неоновое меню Soul Knight в подземелье.png`, игровой интерфейс собран из PNG-атласа `Пиксельный атлас интерфейса PvP-шутера (1).png`; герой, кадры ходьбы и оружие берутся из `Пиксельный герой и арсенал оружия.png`, а монстры, предметы, препятствия и порталы — из `Пиксельный атлас подземелья_ монстры и артефакты.png`.

## Запуск

### Быстрый способ на Windows

Дважды нажмите `start-game.bat`. Игра откроется по адресу <http://127.0.0.1:4173>.

### Через терминал

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Затем откройте <http://127.0.0.1:4173>.

## Управление

- **WASD / стрелки** — движение
- **Мышь** — прицеливание
- **ЛКМ** — стрельба
- **Space** — рывок с короткой неуязвимостью
- **Q / ПКМ** — энергоимпульс
- **1–3 / колесо мыши** — смена оружия
- **Esc** — пауза

На устройствах с сенсорным экраном автоматически появляются два виртуальных стика и кнопки способностей.

## Что реализовано

- 5 волн и финальный босс «Страж Пустоты»;
- четыре обычных типа противников с разным поведением;
- несколько визуальных вариантов монстров, предметы, препятствия и снаряды из атласа подземелья;
- импульсный бластер, дробовик и криобластер из нового оружейного атласа;
- восьмикадровая анимация ходьбы, отдельные позы направлений, рывка и падения;
- случайный выбор постоянных усилений после каждой волны;
- здоровье, восстанавливаемый щит, энергия, монеты и рекорд;
- частицы, отдача, тряска камеры, мини-карта и процедурный звук;
- адаптивный интерфейс для компьютеров и мобильных устройств.

Все файлы игры автономны — внешние библиотеки и сетевые ресурсы не используются.
